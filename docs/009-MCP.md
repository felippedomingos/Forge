# 009 — MCP Integration

## Status

Not started — Phase 3 (Architecture)

## Purpose

How Forge exposes external tools (Git, Azure DevOps, az cli, databases, Docker, browser/Playwright) to agents via MCP servers, and how new tools are added without touching agent core logic.

## Planned Outline

- MCP servers required for MVP (Git, filesystem, terminal)
- MCP servers for Phase 2 (Azure DevOps, az cli, browser)
- Tool permission model (which agent role may call which tool)
- Error handling and timeouts across MCP calls
