# 001 — Requirements

## Status

Not started — Phase 1 (Product)

## Purpose

Formal functional and non-functional requirements derived from [[000-Vision]], written as testable statements (SHALL/SHOULD), organized by the lifecycle stage they govern.

## Planned Outline

- Functional requirements — Task management (creation, cross-project view, filtering)
- Functional requirements — Planner agent (investigation sources, question/blocked protocol)
- Functional requirements — Prioritizer agent
- Functional requirements — Developer agent (sync, worktree, branch, execution, live observability)
- Functional requirements — Publish gate and Deploy agent
- Functional requirements — Review gate and Git agent (commit, push, PR, worktree cleanup)
- Functional requirements — Production confirmation
- Non-functional requirements — Performance, concurrency limits, cost ceilings
- Non-functional requirements — Security and secrets handling
- Non-functional requirements — Auditability
- Traceability matrix (requirement → architecture component → ADR)
